# 김혜선 · 도해

**일상의 작은 불편을 해결하는 앱을 기획하고 운영합니다.**

집중을 시작하는 일, 대본을 외우는 일처럼 반복되는 과정에서 더 편한 방법을 찾습니다.
AI 도구를 활용해 아이디어를 앱으로 구현하고, 직접 사용하며 기능과 사용 흐름을 다듬고 있습니다.

## 앱을 만드는 방식

- **문제와 사용 흐름부터 정합니다.** 누구에게 어떤 순간이 불편한지 살피고 핵심 기능을 고릅니다.
- **AI 도구와 함께 구현합니다.** Claude Code와 Codex 등을 활용하며 기능 요구사항과 수정 방향을 정합니다.
- **사용하며 확인합니다.** 화면 이동, 입력, 저장, 반복 사용 과정에서 생기는 불편을 점검합니다.
- **출시 이후에도 개선합니다.** 사용자 의견과 실제 사용 경험을 바탕으로 다음 작업의 우선순위를 정합니다.
